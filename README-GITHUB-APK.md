# Build APK on GitHub Actions

1. Create a private GitHub repository.
2. Upload the extracted contents of this project (do not upload the outer ZIP).
3. Make sure `.github/workflows/build-apk.yml` is included.
4. Open the **Actions** tab and run **Build APK** (or push to main).
5. Open the completed workflow run and download the **interview-assistant-apk** artifact.
6. Extract the artifact and install the APK on the vivo X300 Pro.

No USB connection to the X300 Pro is required.
